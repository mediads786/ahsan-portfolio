Portfolio case study

ERP Order Integration Gateway: reliable Shopify-to-ERP order sync

The problem

When a store sends orders to an ERP, the usual failures are quiet ones: a webhook arrives twice and creates two orders, the ERP is down for ten minutes and orders vanish, or someone fixes a failed order by hand and nobody knows what changed. I come from 25+ years of running operations, so I built the tool I would have wanted: an integration layer where no order is lost or duplicated, and every action can be traced.

What it does

  • Receives Shopify webhooks and verifies the HMAC signature. Unsigned or tampered requests are refused.
  • Handles duplicates safely. A repeated webhook creates exactly one order, one job and one ERP order. The same webhook ID with a changed payload is refused.
  • Processes orders through a database-backed queue with a worker, automatic retries, dead-letter handling, recovery of stuck jobs, and a manual retry.
  • Pushes confirmed orders to an ERP through an adapter. A mock ERP is included for demos, and a real adapter for Odoo 19 Community was verified live.
  • Gives operators admin pages with a full audit trail, plus approval-governed actions (for example, cancelling an order needs an approver) and natural-language proposals that are reviewed before anything executes.

Proof it works

  • A real Shopify dev-store order was confirmed in Odoo with matching lines, quantities and totals (20/20 checks).
  • 284 automated tests pass offline, and GitHub Actions CI runs on every push.
  • Currency amounts are preserved exactly (a USD 10.00 order stays USD 10.00).

Deployed on AWS, and tested like production

  • Runs on a single EC2 instance with Docker Compose, with Caddy providing trusted HTTPS, an HTTP-to-HTTPS redirect and security headers.
  • Only the proxy is exposed publicly. The firewall, container health checks, restart policies and log rotation were all verified, and the instance enforces IMDSv2.
  • Nightly database backups have restricted permissions and an integrity check. I restored a backup into a temporary database and confirmed the row counts matched across all 11 tables.
  • A full smoke test (HTTPS, authentication, signed order to CONFIRMED) passes on the live deployment.

Stack

Python, FastAPI, PostgreSQL, Docker Compose, Caddy, AWS EC2, Odoo 19, Shopify webhooks, GitHub Actions.

Scope note

Tax calculation sync is not included. Tax settings in the ERP are configured separately.
